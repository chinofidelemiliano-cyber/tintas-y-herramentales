Órdenes de Teams → Inventario

La conexión usa un flujo de Power Automate del propietario del chat. Tus compañeros siguen enviando tablas por Teams y no necesitan cuentas del inventario. Esta página es una guía; no solicita acceso al inventario ni envía mensajes.

Requiere Microsoft Teams y Power Automate autorizados por tu organización. La acción HTTP puede requerir licencia Premium. Solo se importan tablas HTML de texto; una captura, foto o PDF necesita un paso de OCR adicional y no se importa con esta conexión.

1. Activar la base de datos

En Supabase → SQL Editor, ejecuta todo production-tracking-teams.sql. No necesitas volver a ejecutar setup.sql.

2. Crear el flujo en Microsoft

  1. Abre Power Automate → Crear → Flujo de nube automatizado. Usa el disparador de Microsoft Teams When a new chat message is added (cuando se agrega un mensaje nuevo al chat). La cuenta conectada debe participar en el chat. Si tu organización no ofrece ese disparador para el tipo de chat, el administrador debe habilitar una ruta compatible; no uses un disparador de canal para un chat privado.
  2. Prueba el disparador con un mensaje sin datos sensibles. Identifica los campos Chat ID / Conversation ID, Message ID y Body content (HTML). Si el disparador no incluye el cuerpo completo, agrega la acción de Teams Get message details con el chat y el mensaje obtenidos del disparador.
  3. Agrega una condición: el ID del chat debe coincidir con el chat elegido y el HTML debe contener una tabla (<table) y una orden (OP-). Solo en la rama Sí se envía la solicitud. Así los saludos y mensajes normales no se procesan como órdenes.

3. Autorizar el chat en el inventario

En Órdenes de producción → Conectar Teams, pega el ID del chat y pulsa Crear / renovar clave. Copia la URL y la clave: la clave solo se muestra una vez. No la pegues en el chat de Teams ni en esta conversación.

4. Agregar la acción HTTP

En la rama Sí del flujo, agrega una acción HTTP con método POST, la URL de recepción mostrada en el inventario y estos encabezados:

Content-Type: application/json
X-Integration-Key: [clave que acabas de copiar]

En el cuerpo inserta un objeto JSON usando los campos de contenido dinámico del disparador / detalle del mensaje. Los valores entre corchetes son referencias para sustituir, no texto literal. Inserta el HTML como valor de cadena mediante el editor de objetos de Power Automate para que las comillas se escapen correctamente.

{
  "conversation_id": "[Chat ID / Conversation ID]",
  "message_id": "[Message ID]",
  "html": "[Body content completo en HTML]"
}

Activa Entradas seguras / Salidas seguras en la configuración de la acción HTTP para que la clave y los datos de producción no aparezcan en el historial del flujo. No se usa contraseña de Supabase ni clave service_role.

5. Verificar una orden

Envía una tabla de texto con estos encabezados y sus valores: Orden de producción, Número de Parte, Descripción del producto, Cliente, Cantidad de piezas, Cantidad de mts. Opcionalmente incluye FECHA, HORA INICIO, HORA TERMINO y la tabla de Suaje, paso de suaje, paso desarrollo, pleca, TH, UV, Colores y Pantone. Usa fecha DD/MM/AAAA, horas de 24 horas HH:mm y comas para millares (12,725).

La acción HTTP debe responder 200 con order_ids. La orden aparece como Pendiente, con origen Teams, NP y datos programados; no descuenta tinta ni inicia el cronómetro. El inventario revisa órdenes nuevas cada 30 segundos mientras estás en esa sección, sin formularios abiertos; también puedes recargar.

El ID del mensaje evita duplicados en los reintentos. Las ediciones posteriores del mismo mensaje no sobrescriben la orden: los cambios deben revisarse en el inventario. Para registrar consumos, abre la orden → Capturar / completar tintas y pesos. Solo confirmar esos pesos descuenta tinta. Iniciar y Finalizar guardan horas reales independientes del consumo.

Desconectar

Órdenes → Conectar Teams → Desconectar. Renovar la clave invalida la anterior: actualízala en Power Automate. La conexión permite recibir órdenes del chat autorizado; no permite leer inventario ni acceder a otras funciones.
