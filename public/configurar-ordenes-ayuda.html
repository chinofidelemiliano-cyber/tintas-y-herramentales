Administrar la captura de órdenes

Las opciones de captura compartidas se administran desde Configuración → Configuración de órdenes de producción. Se necesita el rol de administrador en Supabase.

1. Activar cuentas y permisos

Si tu sesión muestra «Acceso anterior», ejecuta completo accounts-and-sessions.sql en SQL Editor de Supabase. No reemplaces el inventario ni vuelvas a cargar setup.sql.

2. Autorizar tu cuenta administradora

La cuenta verificada chinofidelemiliano@gmail.com se reconoce como administradora si ya era miembro autorizado. Si todavía no tiene ese rol, ejecuta authorize-owner.sql desde SQL Editor. Ese archivo solo autoriza la cuenta personal indicada; no concede administración a otros usuarios.

3. Activar las tintas de captura

Ejecuta completo order-ink-options.sql. Después vuelve a Configuración y pulsa Comprobar acceso o recarga la página.

Allí podrás administrar el enlace compartido, elegir opciones personalizadas Base Agua o UV y relacionarlas con el catálogo. No compartas contraseñas ni claves secretas.
